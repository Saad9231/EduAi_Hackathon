# EduAI - Smart Learning Platform 🚀

EduAI is a next-generation, AI-powered learning platform designed specifically for Pakistani students (FBISE & PTB Boards). Built with a premium SaaS aesthetic, it leverages Agentic AI to provide personalized tutoring, smart diagnostics, and bilingual support (English and Urdu).

## 🌟 Key Features

- **Agentic AI Tutor:** Real-time bilingual tutoring with interactive chat, Roman Urdu support, and the ability to analyze uploaded homework pictures.
- **Smart Diagnostics & Quizzes:** Adaptive MCQs tailored to the student's mastery level and weak topics.
- **Planner Agent:** An intelligent scheduling system that dynamically generates study tasks based on upcoming exams and identified weaknesses.
- **Role-Based Dashboards:** Dedicated, customized portals for Students, Teachers, and Parents.
- **Resource Management:** Drag-and-drop syllabus and textbook uploads for teachers.
- **Bilingual Interface:** Seamless toggling between English (Inter font) and Urdu (Noto Nastaliq) without reloading.
- **Premium UI/UX:** Deep Slate Dark Mode, Electric Blue Accents, vibrant glassmorphism, and smooth micro-animations.

## 🛠️ Technology Stack

- **Framework:** [Next.js 16](https://nextjs.org/) (App Router)
- **Styling:** [Tailwind CSS v4](https://tailwindcss.com/) & Vanilla CSS for custom Glassmorphism tokens
- **Icons:** [Lucide React](https://lucide.dev/)
- **Charts:** [Recharts](https://recharts.org/)
- **Typography:** `next/font/google` (Inter & Noto Nastaliq Urdu)
- **Deployment Ready:** Dockerized with standalone output and full PWA/SEO integration.

## 🚀 Getting Started

### Prerequisites
Make sure you have Node.js (v20+) installed on your machine.

### Installation

1. Clone the repository and navigate to the project directory:
   ```bash
   cd eduai-frontend
   ```

2. Install dependencies:
   ```bash
   npm install
   ```

3. Start the development server:
   ```bash
   npm run dev
   ```

4. Open [http://localhost:3000](http://localhost:3000) in your browser to see the result. You will be greeted by the multi-step role selection authentication flow.
